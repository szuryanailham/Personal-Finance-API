# Project Title: Personal Finance API

## Description

**Personal Finance API** is a REST API that provides various endpoints to help users manage and monitor their personal finances in an easy, structured, and efficient way.

The API provides endpoints for **recording, managing, and analyzing financial data**, such as income, expenses, transaction categories, and user balances.

Through the available financial data and analysis, users can view their total income and expenses over a specific period, monitor their financial condition, and understand their spending patterns. This information can help users make better and more informed personal financial decisions.

## Features

The features planned for **Personal Finance API** include:

* **Create New Account**

  * Create a new user account.

* **Authentication & Login**

  * Authenticate registered users.
  * Allow users to log in using their credentials.
  * Secure endpoints that require authentication.

* **Income & Expense Management**

  * Record income transactions.
  * Record expense transactions.
  * Update transaction data.
  * Delete transactions.
  * View a list of transactions.

* **Transaction Categorization**

  * Categorize transactions.
  * Create and manage transaction categories.

* **Financial Summary**

  * View total income.
  * View total expenses.
  * View current balance.
  * View financial summaries for a specific period.

* **Transaction Search & Filtering**

  * Search transactions by keyword.
  * Filter transactions by category.
  * Filter transactions by transaction type.
  * Filter transactions by date or period.
